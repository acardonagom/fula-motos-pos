# Fula Motos — Sistema de Gestión de Taller y Punto de Venta (POS)

Aplicación web/escritorio desarrollada a la medida para la administración operativa y financiera de un taller de motocicletas. **Actualmente en producción y uso diario por un cliente real.**

## 🚀 Funcionalidades Principales
* **Punto de Venta (POS):** Registro ágil de ventas con buscador de catálogo en tiempo real y agrupación por métodos de pago.
* **Control de Inventario:** Gestión de existencias y actualización automática de stock con cada operación.
* **Cuentas por Pagar a Proveedores (CXP):** Seguimiento estructurado de facturas, abonos y saldos pendientes.
* **Control Administrativo:** Gestión de descuentos protegidos y registro detallado de mano de obra por técnico.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python, Flask
* **Base de Datos:** SQLite
* **Frontend:** HTML5, Bootstrap 5
